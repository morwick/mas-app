# Kode lama (Next.js)

Folder ini berisi aplikasi versi sebelumnya (Next.js 14 App Router + Supabase
langsung dari server component). Disimpan hanya sebagai **referensi** selama
masa transisi — bukan untuk dijalankan atau dikembangkan lagi.

Versi aktif ada di:

- `../backend/` — REST API Python (FastAPI)
- `../frontend/` — SPA React (Vite + TypeScript)

Skema database (`../supabase/migrations/`) tidak berubah; kedua versi memakai
project Supabase yang sama.
